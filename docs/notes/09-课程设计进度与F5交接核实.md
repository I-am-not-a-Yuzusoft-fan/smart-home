## 3 交接文档逐项一手核实（含 2 处重要新发现）

交接文档 §3 列出了「5 处文档冲突 + 3 处缺口 + 补 seed + 拆票方案」。逐条核查一手源码后结果如下：

### 3.1 五处文档冲突核实

1. **模式级守卫无处安放 — ✅ 属实**
   - `指导书:121` 要求「每个模式由『条件 + 动作集』构成」；`02-需求规格说明书.md:313`（FR-5.2）明确「守卫条件不满足时不执行并说明原因」。
   - `sql/0001_init.sql:171-182` 的 `mode` 表无 `guard` 列；`03-概要设计说明书.md:409-433` 的 `ModeRunner.Advance` 仅处理步骤级 `ChooseStep`；`CONTEXT.md:57` 将 `mode` 定义为纯有序步骤模板。
2. **让位机制两套口径且缺少手动时刻基线读数 — ✅ 属实**
   - `02-需求规格说明书.md:320`（FR-5.9）：30 分钟窗口，环境变化超阈值（±3℃ / ±10%RH / ±200lux）或再次手动或场景执行立即解除。
   - `docs/adr/0002-数据模型与分层.md:96` 以 `command_log.source = 'manual'` 判据；`docs/notes/02-Home-Assistant-参考.md:135` 仍残留「需要一条 `suppressed_until` 字段」的 TODO；`sql/0001_init.sql:117-164` 中 `capability_state` 与 `command_log` 均未存手动时刻的环境基线读数。
   - 另核实 `03-概要设计说明书.md:317` 仅写手动命令打接管标记，未写「场景 run 启动时先清除涉及设备/能力的让位标记」（与 `docs/notes/08-场景编排与策略引擎调研.md:244` 一致）。
3. **`run.status` 用词不一致（`done` vs `ok`）— ✅ 属实**
   - `03-概要设计说明书.md:430` 写 `run.status = done`；`sql/0001_init.sql:187` DDL CHECK 约束为 `('running', 'ok', 'failed', 'cancelled')`，`CONTEXT.md:60` 同样用 `ok`。
   - **补充核实**：`02-需求规格说明书.md:327` 规定单次执行 5 分钟超时，但 `sql/0001_init.sql:187` 的 `run.status` 没有 `'timeout'` 枚举（`:190` 的 `'timeout'` 属于 `run.source` 列），需明确是用 `status='failed'` + 错误原因/错误码表达，还是加迁移扩展枚举。
4. **契约路径三方不一致 — ✅ 属实，且发现重大遗漏（Mode CRUD 端点缺失）**
   - `指导书:328` 示例写 `GET / POST /api/scenes`；`03-概要设计说明书.md:673` 写 4 个端点（`GET /api/modes`、`POST /api/modes/{id}/run`、`GET /api/runs/{id}`、`POST /api/runs/{id}/cancel`）；`04-详细设计说明书.md:249-250` 仅列了前 2 个；`openapi.yaml:1-1694` 目前 21 条路径里 `mode`/`run`/`scene` 全部为 0。
   - **新发现（遗漏）**：`03:673`、`04:249-250` 以及交接文档 §3C 子票 1（写“4 端点”）都**漏掉了 Mode 的创建、详情、修改、删除端点**（`POST /api/modes`、`GET /api/modes/{id}`、`PUT/PATCH /api/modes/{id}`、`DELETE /api/modes/{id}`，以及可选 `GET /api/modes/{id}/runs`）。缺少这些端点，FR-5.1、Issue `#1` 与子票 4（编辑器 UI）无法完成持久化闭环。
5. **`notes/02` 引文 `/docs/scripts/` 过期 — ❌ 核实为误判**
   - 交接文档 §3A 第 5 条与 `docs/notes/08-场景编排与策略引擎调研.md:131,277` 称 `notes/02` 引用了旧路径 `/docs/scripts/`。
   - 一手核实：`docs/notes/02-Home-Assistant-参考.md` 全文检索 `scripts` 为 **0 命中**；该文件 `:56` 原本就已引用 `/docs/automation/building-blocks/` 与 `/docs/automation/modes/`。
   - `notes/02` 实际需要清理的是：`:4` 版本号（`2026.11.2` → `2026.11.3`）、`:33` 旧版 `/docs/scene/` 措辞、`:133` 已完成的 ADR 0002 TODO、`:135` 过时的 `suppressed_until` TODO。
