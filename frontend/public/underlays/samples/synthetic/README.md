# 合成户型图（现代 CAD 风格）

这些图由 `scripts/gen_underlay_samples.py` 用 Pillow 生成，不是扫描件，是可缩放的现代平面图：彩色地面、家具块、门弧、窗线、两侧尺寸链、指北针、图签。

它们有两个用途：

1. **底图功能的示例素材** —— 演示「导入 → 两点定标 → 照着描」时用电脑风格的图，而不是老图纸扫描件。
2. **定标数学的测试基准** —— 只有合成图能精确知道「图上两点真实是多少厘米」，`index.json` 里每张图都记录了 `cm_per_px` 与一组定标点，自动化测试可以直接断言定标误差。

| --- | --- | --- | --- |
| `one-bed-45.png` | 一居室 45 ㎡ | 6.6 × 7.0 m | 0.55 |
| `two-bed-78.png` | 两居室 78 ㎡ | 9.6 × 8.2 m | 0.7375 |

## 重新生成

```bash
python3 scripts/gen_underlay_samples.py
```

脚本只依赖 Pillow；尺寸、家具、门窗都在脚本里以厘米为单位声明，改布局不需要动画图代码。

## index.json

```json
{
  "file": "two-bed-78.png",
  "width_px": 1600,
  "height_px": 1410,
  "cm_per_px": 0.7375,
  "calibration": {
    "p1_px": [149.15, 149.15],
    "p2_px": [1450.85, 149.15],
    "length_cm": 960.0
  }
}
```

`p1_px` / `p2_px` 是户型**外轮廓左上、右上**两个角在图上的像素坐标，真实距离等于图上标的净宽（`length_cm`）。底图功能的定标测试就用这三个数：把两点喂给 `calibrate()`，算出来的 `cm_per_px` 必须和 `cm_per_px` 一致（误差 < 0.1%）。
